# Osenfitters — Clothing Store

## Project Overview
Osenfitters is a responsive clothing-store website created as part of Web Technologies Assignment 2. The website presents clothing collections and products with a clean layout, product images, prices, and Add to Cart buttons.

## Reference Website
- **Name:** Outfitters Pakistan
- **URL:** https://outfitters.com.pk/
and for pictures
- **Name:** Osen
- **URL:** https://osen.pk/

## Project Files
- `index.html` — Homepage
- `product.html` — Product detail page
- `style.css` — Custom styles, if applicable
- `reference-screenshot.png` — Screenshot of the reference website
- `completion.pdf` — Assignment completion report

## How to Run
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Open `picnicclub.html` to view one collection of women category.
4. Open `shortcake.html` to view the product detail page.

## Note
This is a front-end academic project. Add to Cart buttons are visual elements and do not perform cart operations unless functionality has been implemented separately.
